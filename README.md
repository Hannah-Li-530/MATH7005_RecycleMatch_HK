# RecycleMatch HK — 项目资料夹

**项目题目：** RecycleMatch HK: A Location-Based Recommendation Tool for Public Recycling Points（香港公共回收设施就近推荐工具）  
**课程：** MATH7005 2026/2027  
**更新日期：** 2026-11-04

## 项目简介

面向香港居民、学生及访客，按用户选择的回收物品和起点，筛选并排序公众可使用的回收点；提供最近单点和尽量减少停靠点两种方案，并可跳转 Google Maps 查看步行路线。产品定位是**辅助决策工具**，不是实时回收设施状态或交通预测器。

## 当前可用功能

1. Python 网站支持地址/地点搜索、浏览器一次性定位及手动坐标。
2. 选择一种或多种回收物品，查找可接收所选物品的回收点。
3. 按 Haversine 直线距离排序，提供“单点最近”和“尽量少跑点”方案。后者使用逐步贪心覆盖启发式。
4. 「有赏回收」按距离查询环保署入樽机名录，显示开放时间、技术支援电话和回赠说明。
5. 从推荐卡片打开 Google Maps 步行路线。Google Maps 负责路线规划；原型中的距离是直线距离，不是步行距离。

## 当前状态与重要边界

- 正式网站使用 HTML Demo 的双栏卡片布局。Python 提供数据、地址查询和推荐接口。默认按距离展示，高级选项可限制直线搜索范围。Windows 启动入口为 `python_app/start_windows.bat`。
- 当前项目主数据是 data.gov.hk 上 EPD 的回收点数据。外部地点搜索、坐标转换和 Google Maps 路线仅用于补足交互。
- 清洗版包含 5,868 条公众可用记录；用户已确认沿用当前版本，不再继续清洗。最终报告应说明筛选口径，并保留原始文件以便追溯。
- 开放时间、现场接收状态和路线距离可能缺失或变化；当前工具不声称实时营业/可投放状态。
- Apriori 材料共现和区级点位统计由 `python_app/run_analysis.py` 独立运行。以 2% 最小支持度和 60% 最小置信度生成 1,029 个频繁项集及 5,056 条单物料后件规则。区级统计覆盖 18 区。网站推荐使用物料筛选、直线距离和贪心覆盖。
- 课程项目要求最终报告、完整 Python 代码、10 分钟产品演示及约 20 分钟问答；报告须说明 AI 使用。3 分钟 pitch 截止日期为 2026-10-26。
